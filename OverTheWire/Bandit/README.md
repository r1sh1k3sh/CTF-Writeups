# Bandit

> **Platform:** OverTheWire | **Levels:** 0 → 33

A complete set of write-ups for the [Bandit wargame](https://overthewire.org/wargames/bandit/), covering all 34 levels. Bandit is aimed at absolute beginners and teaches the basics of Linux, networking, Git, and CTF-style problem solving.

I completed each level manually and documented the commands, observations, and approach used to solve it. The write-ups are intended as learning notes rather than authoritative solutions, so there may be alternative methods for completing some challenges.

## About These Write-Ups

These write-ups were created while working through the Bandit wargame and are meant to document my learning process. Some sections were later edited for clarity, consistency, and readability, but all solutions were verified by completing the challenges myself.
