# What is this?

Each TryHackMe room keeps the commands I ran, what they returned, screenshots, and the full attack chain. Bandit keeps one short note per level. The notes cover Nmap, Gobuster, web enumeration, Linux privilege escalation, SUID and PATH hijacks, capabilities, SSH, and basic crypto and stego.

New to this repo? Read [Wonderland](./TryHackMe/Wonderland/) first. It shows the full format: recon, enumeration, initial access, lateral movement, privilege escalation, flags, attack chain, mitigations.
